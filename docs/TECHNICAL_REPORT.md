# Udgam-384M technical report

The technical report for Udgam-384M-Base, Udgam-384M-Base-4K and Udgam-384M-Chat is published by Udgam Labs at:

- **Web:** [udgamlabs.com/reports/udgam-384m](https://udgamlabs.com/reports/udgam-384m)
- **PDF:** [udgamlabs.com/reports/udgam-384m.pdf](https://udgamlabs.com/reports/udgam-384m.pdf)

It covers the architecture, training at a high level, inference (chat and tool-call format, `<bos>` handling,
recommended settings, speed and memory), evaluation against other small open models with every setting stated,
quantisation, safety and limitations.

The shorter report first published in this file on 10 October 2026 was replaced by that report on 17 October 2026.
The published evaluation results are unchanged: a re-run of the released Q8_0 file on 17 October 2026 reproduced them.
